# NOTICE

## Third-party references

No third-party source code is vendored in this repository. The algorithms here
were written from scratch; the following projects were studied for comparison
only, and are **not** copied or linked into pxconv:

- **PixelOE** (KohakuBlueleaf, Apache-2.0) — outline-aware pixelization.
  Note: its pipeline converts input to RGB (`Image.open(...).convert("RGB")`),
  so it does not preserve the alpha channel. pxconv keeps RGBA end to end.
- **BetterPixelArtDownscale** (MidFord, MIT) — independent work that also treats
  alpha coverage as pixel existence; pxconv adds fractional cell boundaries,
  core-pixel colour sampling and thin-structure rescue on top of that idea.
- **PixelArtConverter** (ahmetolcum, MIT), **pixfix** (lovelaced, MIT) —
  GUI / CLI pixel-art converters; useful as feature references (batch, presets,
  shared palette across animation frames).

## Assets

- `assets/sample_raw.png` is **synthetic**, generated by `tools/make_sample.py`
  (the same script ships in this repo) — a crude shapes drawing downsampled with
  Lanczos to produce soft alpha edges. No third-party artwork is included, and
  no personal/AI-generated portrait from the author's machine is published here.
- `assets/*_preview.png` are generated by the tool itself (nearest-neighbour
  upscale over a checkerboard).
